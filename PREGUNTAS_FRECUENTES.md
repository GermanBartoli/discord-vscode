# Preguntas frecuentes de Discord Presence de Germán

## ¿Cómo vuelvo a conectar Discord desde VS Code?

Abrí Discord de escritorio y ejecutá **Reconnect Discord Presence to Discord** desde la paleta de comandos de VS Code.

## ¿Qué datos ayudan a reproducir un error?

Indicá la versión de VS Code y el estado de Discord de escritorio. Describí qué esperabas y qué pasó. Encontrás los pasos para enviar el informe en [Cómo colaborar](CONTRIBUTING.md).
